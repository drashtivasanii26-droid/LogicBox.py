# LogicBox

## Project Description

LogicBox is a simple Python menu-driven program.
It is designed to generate star patterns and analyze a range of numbers.

## Features

### 1. Generate a Pattern

The program generates a star pattern based on the number of rows entered by the user.

Example:

*
**
***
****
*****

### 2. Analyze a Range of Numbers

The program takes a starting number and an ending number.

It:
- Checks whether each number is Even or Odd.
- Calculates the sum of all numbers in the given range.

Example:

Number 10 is Even
Number 11 is Odd
Number 12 is Even
Number 13 is Odd
Number 14 is Even
Number 15 is Odd

Sum of all numbers from 10 to 15 is: 75

### 3. Exit

The program exits when the user selects option 3.

## Technologies Used

- Python 3

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

python LogicBox.py

## Menu Options

1. Generate a Pattern
2. Analyze a Range of Numbers
3. Exit
